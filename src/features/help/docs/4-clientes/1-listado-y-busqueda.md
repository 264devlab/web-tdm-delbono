# Listado y Búsqueda de Clientes

El sistema almacena automáticamente un registro de cada cliente que interactúa con la petshop. La administración centralizada te permite gestionar sus datos de contacto y acceder a sus historiales de visitas de forma sencilla.

![Buscador de Clientes](/help/images/4-clientes/1-listado-y-busqueda.webp)

## Base de Clientes Sin Registro Obligatorio
Para simplificar el proceso de reserva y maximizar las conversiones, **los clientes no necesitan registrarse ni recordar una contraseña** para reservar turnos en la web.
- El sistema utiliza el **correo electrónico** como identificador único.
- Si un cliente ingresa un email que ya utilizó en el pasado, el sistema lo reconoce y autocompleta su nombre, apellido y teléfono, vinculando el nuevo turno a su ficha histórica.

## Buscador Inteligente
En la sección **"Clientes"** del panel lateral, encontrarás el listado completo de clientes. Puedes filtrar la lista utilizando la barra de búsqueda superior:
- **Búsqueda por texto:** Escribe el nombre, apellido, correo electrónico o teléfono del cliente.
- El filtrado es instantáneo y se actualiza en tiempo real a medida que escribes.

> [!NOTE]
> La lista de clientes incluye un botón para ver los detalles individuales de cada persona, permitiendo editar su información de contacto (teléfono, nombre, apellido) si detectas algún error de escritura o si el cliente solicita actualizar sus datos.
