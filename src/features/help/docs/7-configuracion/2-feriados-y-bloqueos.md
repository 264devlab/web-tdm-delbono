# Gestión de Feriados y Bloqueos de Agenda

Es común que tu petshop deba cerrar en días específicos por feriados nacionales, vacaciones del personal o mantenimiento de las instalaciones. El sistema te permite bloquear fechas completas o franjas horarias específicas para evitar que ingresen reservas web no deseadas.

![Feriados y Bloqueos](/help/images/7-configuracion/2-feriados-y-bloqueos.webp)

## Tipos de Bloqueo

### 1. Bloqueo de Día Completo (Feriado)
- **Cuándo usarlo:** Días no laborables, feriados patrios o vacaciones colectivas.
- **Cómo crearlo:** En la pestaña **"Feriados y Bloqueos"**, haz clic en "Agregar Bloqueo", selecciona la fecha y deja el campo de hora de inicio y fin vacíos (o selecciona todo el día).
- **Efecto:** Ningún cliente podrá seleccionar esa fecha en el calendario de reservas de la web pública.

### 2. Bloqueo de Franja Horaria Específica
- **Cuándo usarlo:** Si necesitas cerrar el local antes de tiempo un día específico, o si hay una reunión de personal a media tarde.
- **Cómo crearlo:** Indica la fecha, selecciona la **Hora de Inicio** (ej. 17:00) y la **Hora de Fin** (ej. 19:00).
- **Efecto:** El sistema inhabilitará únicamente los turnos comprendidos en ese rango para ese día, manteniendo libre el resto de la jornada (mañana o mediodía).

## Listado y Eliminación de Bloqueos
Debajo del formulario de creación verás el listado de bloqueos activos ordenados por fecha.
- Cada registro muestra la fecha, las horas (o "Día Completo") y el motivo del bloqueo (ej: "Día del Trabajador", "Desinfección").
- Puedes eliminar cualquier bloqueo haciendo clic en el ícono de tachito de basura (**Eliminar**).
- Al eliminar un bloqueo, los horarios de ese día vuelven a estar disponibles para reserva web de forma inmediata.

> [!IMPORTANT]
> El bloqueo de agenda impide que ingresen **nuevas reservas** desde la web. Si ya tenías reservas confirmadas para ese día y horario antes de registrar el bloqueo, deberás reprogramar o cancelar esos turnos de forma manual en el calendario, ya que el sistema no cancela reservas existentes de forma automática para evitar pérdidas de datos accidentales.
